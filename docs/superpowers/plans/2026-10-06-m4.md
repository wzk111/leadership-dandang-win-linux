# M4 product layer implementation plan

> For agentic workers: use subagent-driven-development for isolated implementation/review tasks, TDD, and verification-before-completion. The accepted M4 specification is the approved design. Continue the established repository delivery workflow; stop before M5.

**Goal:** Six explicit AI features, local profile, snapshot-based refinements, four isolated provider configurations and credentials.
**Architecture:** Preserve Linux adapters. Extend core values and PromptBuilder first, then controller/UI consent boundaries. Add protocol adapters behind AIService and a credential router behind ISecretStore. UI does not know provider JSON or construct prompts.
**Tech Stack:** C++20, Qt 6.2 Widgets/Network/Test, CMake, libsecret, Ubuntu 22.04 GitHub Actions.
